# SecureCloud — Windows 11 Local Setup & Cloud Free-Tier Guide

This guide provides end-to-end instructions for configuring and running **SecureCloud** on Windows 11 using PowerShell and VS Code with **₹0 budget** (100% free tiers).

---

## 1. Local Prerequisites Check

Ensure you have Node.js and Git installed on your Windows machine:

1. Open PowerShell and verify:
   ```powershell
   node -v
   npm -v
   git --version
   ```
2. Recommended: Node.js LTS (v20+ or v24+) is verified and working.
3. If script execution errors occur in PowerShell, run (as Administrator once):
   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
   ```

## 2. MongoDB Atlas Setup (Free M0 Cluster)

MongoDB Atlas provides a permanent free M0 sandbox (512 MB storage, shared RAM), which is ideal for SecureCloud metadata, sessions, and audit logs.

### Step 2.1: Create Your Account & Free Cluster
1. Navigate to [https://www.mongodb.com/cloud/atlas](https://www.mongodb.com/cloud/atlas) and sign up or sign in.
2. In your dashboard, click **"Create"** or **"Build a Database"**.
3. Choose the **M0 (Free)** tier tile.
4. Select a cloud provider and region closest to you (e.g., AWS `ap-south-1` Mumbai or your local region).
5. Name your cluster (e.g., `Cluster0` or `securecloud-cluster`) and click **"Create Deployment"**.

### Step 2.2: Create a Database User
1. In the security quickstart dialog (or left navigation **Security → Database Access**):
2. Click **"Add New Database User"**.
3. Authentication Method: **Password**.
4. Set a Username (e.g., `securecloud_admin`).
5. Set an Autogenerated or custom Password (e.g., `SecurePass2026!`).
   > **Note on Special Characters**: If your password contains `@`, `:`, `/`, or `%`, encode them (e.g. `@` is `%40`) or use alphanumeric characters with basic punctuation (`!`, `-`, `_`).
6. Set Database User Privileges: **Read and write to any database** (built-in role).
7. Click **"Add User"**.

### Step 2.3: Configure IP Network Allowlist
1. In the left navigation, go to **Security → Network Access**.
2. Click **"Add IP Address"**.
3. For local development on dynamic Wi-Fi/home networks, click **"Allow Access from Anywhere"** (`0.0.0.0/0`).
4. Click **"Confirm"**. It will become active within ~30 seconds.

### Step 2.4: Obtain Connection String
1. Go to **Deployments → Database**.
2. Click the **"Connect"** button next to your cluster.
3. Select **"Drivers"** (Node.js).
4. Copy the connection string format:
   ```text
   mongodb+srv://securecloud_admin:<password>@cluster0.abcde.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0
   ```
5. Replace `<password>` with your actual database user password.
6. Specify the database name before the `?` query string:
   ```text
   mongodb+srv://securecloud_admin:YourPassword123@cluster0.abcde.mongodb.net/securecloud?retryWrites=true&w=majority
   ```
7. Paste this into `server/.env` under `MONGODB_URI`.

## 3. Supabase Storage Setup (Free Project & Private Bucket)

Supabase provides 1 GB of free private object storage with high-speed signed URLs and direct streaming.

### Step 3.1: Create Free Project
1. Navigate to [https://supabase.com](https://supabase.com) and sign in with GitHub.
2. Click **"New project"**.
3. Choose an Organization.
4. Project Name: `SecureCloud`.
5. Database Password: Generate and save a strong password.
6. Region: Select the region nearest to you.
7. Pricing Plan: **Free** (select default ₹0 plan).
8. Click **"Create new project"** (takes ~1-2 minutes to provision).

### Step 3.2: Retrieve API Keys (Service Role Key)
1. In the left sidebar, click **Project Settings** (gear icon) → **API**.
2. Copy the **Project URL** (e.g., `https://abcdefghijklm.supabase.co`).
   - Paste into `server/.env` as `SUPABASE_URL`.
3. In the "Project API keys" section:
   - Find the key labeled **`service_role`** (secret).
   - Click **"Reveal"** and copy this key.
   - Paste into `server/.env` as `SUPABASE_SERVICE_ROLE_KEY`.
   > **CRITICAL SECURITY NOTE**: Never use the `anon` (public) key for backend file storage operations. The `service_role` key gives backend bypass privileges and is strictly kept on your server. It is NEVER sent to the React frontend.

### Step 3.3: Create Private Storage Bucket
1. In the left sidebar, click **Storage** (bucket icon).
2. Click **"New bucket"**.
3. Bucket name: **`securecloud-files`** (must match `SUPABASE_STORAGE_BUCKET` in `.env`).
4. Ensure **Public bucket** toggle is **OFF (Disabled)**. The bucket MUST be private.
5. Allowed MIME types: leave blank or accept all.
6. Max file size: leave default or set to `25MB`.
7. Click **"Save"**.

## 4. Environment Variables Reference

### Backend (`server/.env`)
Create or edit `server/.env` with your actual credentials:

```dotenv
# Application Environment & Server Port
NODE_ENV=development
PORT=5000
CLIENT_ORIGIN=http://localhost:5173

# MongoDB Atlas
MONGODB_URI=mongodb+srv://securecloud_admin:YOUR_PASSWORD@cluster0.abcde.mongodb.net/securecloud?retryWrites=true&w=majority

# Supabase Storage
SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
SUPABASE_SERVICE_ROLE_KEY=YOUR_SUPABASE_SERVICE_ROLE_KEY
SUPABASE_STORAGE_BUCKET=securecloud-files

# JWT Secrets (Random 32+ char strings)
JWT_ACCESS_SECRET=c28f9d8a1e3b5c7d9e1f2a3b4c5d6e7f8a9b0c1d2e3f4a5b6c7d8e9f0a1b2c3d
JWT_REFRESH_SECRET=e7f8a9b0c1d2e3f4a5b6c7d8e9f0a1b2c28f9d8a1e3b5c7d9e1f2a3b4c5d6e7f
JWT_ACCESS_EXPIRY=15m
JWT_REFRESH_EXPIRY_DAYS=7

# File Limits & Storage Quotas
MAX_FILE_SIZE_BYTES=26214400
DEFAULT_USER_QUOTA_BYTES=104857600

# Cookie Settings for Local Development
COOKIE_SECURE=false
COOKIE_SAME_SITE=lax
```

### Frontend (`client/.env`)
Create or edit `client/.env`:

```dotenv
VITE_API_BASE_URL=http://localhost:5000/api
```

## 5. Verification Commands

1. **Verify Database Connection**:
   ```powershell
   npm run test:db
   # Or from server folder:
   cd server
   npm run test:db
   ```
2. **Start Backend Server**:
   ```powershell
   npm run dev:server
   ```
   Open `http://localhost:5000/api/health` in your browser. You should see `{ "status": "ok" }`.
3. **Start Frontend Dev Server**:
   ```powershell
   npm run dev:client
   ```
   Open `http://localhost:5173` in your browser.
